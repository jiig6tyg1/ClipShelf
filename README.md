# ClipShelf 1.00

Windowsのクリップボード履歴のように使える、Mac向けの軽量な履歴アプリです。SwiftUIとAppKitで実装しています。

## 機能

- **Ctrl＋V**で入力位置の近くに履歴を表示。ショートカットは変更可能。
- **↑↓で選択、Enterで元のアプリへ貼り付け**。カードのクリックにも対応。
- テキスト・画像の履歴、検索、ピン留め、個別削除。
- メニューバーからの呼び出し、ログイン時の自動起動。
- ライト／ダークテーマ。macOS 26以降ではLiquid Glassに対応。
- 履歴データは最大80件／48 MiB、縮小画像キャッシュは最大12 MiB。
- ネットワーク通信・アカウント登録不要。履歴はMacの中に保存します。

## 動作環境

Apple Silicon搭載Mac、macOS 13以降。macOS 13〜25では通常の半透明表示に切り替わります。Intel版は提供していません。実機確認はmacOS 27.0.1で行っています。

## インストール

1. [Releases](https://github.com/jiig6tyg1/ClipShelf/releases)から`ClipShelf-1.00-macOS-arm64.zip`をダウンロードして展開します。
2. `ClipShelf.app`をアプリケーションフォルダへ移動して開きます。
3. アプリの設定から、macOSのアクセシビリティでClipShelfを許可してください。
4. 貼り付け先の入力欄を選んでCtrl＋Vを押します。

**配布バイナリはad-hoc署名で、Developer ID署名・Appleの公証は行っていません。** macOSにより起動が制限される場合があります。ソースからのビルドも可能です。

## 使い方

| 操作 | 動作 |
| --- | --- |
| Ctrl＋V | 履歴の表示・非表示 |
| ↑／↓ | 履歴の選択 |
| Enter／カードをクリック | 元の入力先へ貼り付け |
| Esc | 閉じる |
| ⌘, | 設定 |
| メニューバーを左クリック | 履歴の表示・非表示 |
| メニューバーを右クリック | 設定・終了 |

入力位置を取得できないアプリでは、マウスポインタ付近に表示します。「ログイン時に開く」は設定で有効にできます。

### 許可済みなのに貼り付けられない場合

設定画面に表示される「アクセシビリティ」「キー送信」の判定を確認してください。

1. macOSのプライバシー設定で既存のClipShelfを削除し、`/Applications/ClipShelf.app`を追加して有効にします。
2. **ClipShelfを終了して起動し直します。** キー送信の権限判定が再起動まで反映されない場合があります。

開発用署名のため、バージョン更新や再ビルドにより再許可が必要になることがあります。権限がない場合はコピーまで行い、案内を表示します。

## 履歴とプライバシー

- 初期設定はメモリ内のみです。「終了後も履歴を保存」を有効にすると、`~/Library/Application Support/ClipShelf/history.plist`へ保存します。
- 保存ファイルは暗号化されません。保存をオフにすると新旧の履歴ファイルを削除します。
- 既知の機密・一時クリップボード形式を除外しますが、すべてのパスワードや機密情報を判別できるものではありません。
- 履歴の上限に達すると古い未ピン留め項目を整理します。ピン留めは20件までです。
- テキスト1 MB、画像8 MB／4,000万画素まで。表示は縮小画像ですが、貼り付けには原本を使用します。
- 0.6秒ごとに収集します。非常に速い連続コピーでは途中の内容を取りこぼす場合があります。
- 48 MiBは履歴データの上限であり、アプリ全体の使用メモリ上限ではありません。

## ビルド・テスト

macOS 26以降のSDKを含むXcodeとSwiftが必要です。外部パッケージは使用しません。

```sh
zsh build.sh
zsh test.sh
zsh benchmark.sh
```

`ClipShelf.app`が生成されます。テスト・ベンチマークは専用クリップボードを使用し、通常のクリップボードを変更しません。GUI検証用の`Tests/PasteHarness.swift`は例外で、検証テキストを通常のクリップボードへ書き込みます。

画像160回投入の履歴処理ベンチマークでは、最適化前290.5 MiBから72.1 MiBへ削減しました。描画UI・永続保存を含まない単回比較です。条件と生データは[測定レポート](MEMORY-REPORT.txt)と[Benchmarks](Benchmarks/)を参照してください。

## 制約

- ファイル履歴やリッチテキストの書式保持は対象外です。
- 入力位置や貼り付けへの対応はアプリによって異なります。
- アクセシビリティ許可済みの専用AppKit入力欄で、Enterのみの貼り付けを確認しています。すべてのエディタでの動作を保証するものではありません。
- バイナリは未公証です。macOS旧版での実機確認、Intel対応、安定した配布用署名は今後の課題です。
